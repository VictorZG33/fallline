# Fall Line

A static PWA (no build step) served by GitHub Pages at https://wentaoz.com/fallline/.
See README.md for what it does and where each piece lives.

## Conventions

- Plain ES modules in `js/`, loaded by `index.html`. No bundler, no npm runtime deps.
- Third-party code is vendored and pinned in `vendor/` (MapLibre GL JS 6.13.0,
  maplibre-contour 0.1.1) so the service worker can control MapLibre's worker
  and the app works offline. Upgrade by copying the new `dist/` files over.
- All URLs are relative: the app lives under `/fallline/`, not at the root.
- Interface text goes through `t()` in `js/i18n.js`; add every key in both `en` and `zh`.
- Numbers with units go through `js/format.js` (metric or imperial).
- When you change a file listed in `SHELL_FILES` in `sw.js`, bump `VERSION`.
- `data/` is generated by `tools/build-data.mjs`; don't edit it by hand.

## Testing

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Then drive it with Playwright (Chromium with `--use-angle=swiftshader` for WebGL).
`window.fallline.map` is the MapLibre map. The map hash (`#zoom/lat/lon/bearing/pitch`)
sets the view, e.g. `#13.4/44.53/-72.79/290/62` for Stowe.

## Terrain engine

`js/terrain.js` is the core: Mapterhorn terrarium tiles (512 px, webp, max zoom
varies by region: 404 above the finest data, so `bestZoom` walks down). Slope uses
Horn's method on native-resolution heights with a baseline of about 12 m, then
interpolates the gradient to the output tile. Keep it free of DOM APIs; it runs
in `terrain-worker.js` and, as a fallback, on the main thread.
